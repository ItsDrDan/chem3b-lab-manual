## Build steps (verified)

```bash
cd source
ln -s "<path to>/node_modules" node_modules    # or: npm install
NOPROMPT=1 TOCJSON=tocpages.json ~/.local/node/bin/node master.js fig out/CHEM3B_Lab_Manual.docx
~/.local/node/bin/node src/exp04.js fig out/exp04.docx    # one lab
./remap.sh N    # macOS + Microsoft Word: page map; lists pages that end high (spills)
python3 toc_from_map.py out/pagemap/pmN.txt tocpages.json
```

- **Determinism:** rebuilding `74efdc9` gives a `word/document.xml` and `styles.xml` byte-identical to the published DOCX. Only the timestamps in `docProps/core.xml` differ.
- **PDF:** generated by hand with Word's export (AppleScript export fails, error −1708). The split PDFs are cut with pypdf. The PDF is therefore the one artifact this audit could not regenerate (see RELEASE-GATE.md).

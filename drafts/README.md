# Drafts

Labs in development for the CHEM 3B Laboratory Manual (Alexandra Aloia and Daniel Kwasniewski, CC BY 4.0).
These are **not part of the manual yet**: they have no experiment number, have not been run in a teaching
lab, and still need a trial run and a safety (EHS) review. Each draft has a NOTES file with the stockroom prep,
timing, safety points and the choices the authors still need to make.

| Draft | Word file | Notes | Course outline lab topic |
|---|---|---|---|
| Saponification: Making and Testing Soap | [Draft_Soap.docx](Draft_Soap.docx) | [Draft_Soap_NOTES.md](Draft_Soap_NOTES.md) | Lipids: saponification, soap properties |
| Digestion of Foods (bench or mock-data option) | [Draft_Digestion.docx](Draft_Digestion.docx) | [Draft_Digestion_NOTES.md](Draft_Digestion_NOTES.md) | Metabolism: digestion of foods |
| Urinalysis (simulated urine) | [Draft_Urinalysis.docx](Draft_Urinalysis.docx) | [Draft_Urinalysis_NOTES.md](Draft_Urinalysis_NOTES.md) | Analysis of "urine": glucose, ketone bodies, protein, urobilinogen, electrolytes |
| Experiment 11, paper chromatography version | [Exp11_AminoAcids_PaperChromatography_ALTERNATE.docx](Exp11_AminoAcids_PaperChromatography_ALTERNATE.docx) | — | Alternate for courses without cellulose TLC plates |

Sources for the new drafts are `source/src/draft_*.js` (build: `node src/draft_soap.js fig ../drafts/Draft_Soap.docx` from `source/`).
